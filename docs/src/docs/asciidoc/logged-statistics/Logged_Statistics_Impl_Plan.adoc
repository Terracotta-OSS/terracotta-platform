== Implementation Plan

=== Design Principles

* **Isolated Implementation**: Minimize modifications to existing code
* **Registry Pattern**: Components register metrics with a central registry
* **Event-Driven**: Log on schedule AND on topology/failover events
* **Thread-Safe**: Atomic operations for metric updates
* **Single Module**: All statistics code in `com.tc.stats.logged` package
* **Non-Fixed Rate Scheduling**: Execute → Collect → Reset → Log → Schedule Next
* **Counter Wrapping**: Long counters wrap from Long.MAX_VALUE to 0

=== Architecture Overview

The implementation uses a registry-based architecture where:

* Components own their metric objects
* Metrics are registered with a central registry
* Registry defines display order for the formatter
* Formatter queries registry for metrics in the correct order
* All statistics code is isolated in `com.tc.stats.logged` package

=== Metric Types

**Gauge**::
Tracks current value (can be positive or negative). Reports: current, +delta, -delta.
Components can use a Supplier to get the current value dynamically.

**Counter**::
Monotonically increasing value (only goes up). Can be used standalone or as a parent for MeteredCounter.
Handles overflow by wrapping from Long.MAX_VALUE to 0.

**MeteredCounter**::
Acts as a view on an existing Counter (parent-child relationship), reporting delta since last reset.
Does not have its own increment methods - increments happen on the parent Counter.
Handles counter overflow automatically when calculating deltas.
When counter wraps, calculates: `delta = (Long.MAX_VALUE - lastValue) + currentValue + 1`

=== Key Components

**MetricsRegistry**::
* Defines display order for formatter
* Provides atomic snapshot and reset of all metrics
* Maps metric names (V, P, C, F, S, EIC, CIC, SIC, QIC) to metric instances

**StatisticsLogger**::
* Non-fixed-rate scheduling: Execute → Collect → Reset → Log → Schedule Next
* Listens for topology/failover events
* Triggers immediate logging on events
* Configurable period via system property

**StatisticsFormatter**::
* Queries registry for metrics in display order
* Formats metrics in fixed-width format with dynamic expansion
* Handles missing metrics gracefully (GC'd components)

**Metric Providers**::
* Each provider owns its metric objects
* Updates metrics directly within the component
* Isolated - only depends on MetricsRegistry for registration

=== Integration Points

Only **3 places** need modification in existing code:

1. **DistributedObjectServer** - Initialize `StatisticsService` and wire state change listener
2. **ManagedEntityImpl.invoke()** - Add invocation tracking for entity invocations
3. **EntityManagerImpl** - Add interceptor field and pass to ManagedEntityImpl

All other functionality is self-contained in the `com.tc.stats.logged` package.

**Note**: The actual implementation integrated the interceptor in `ManagedEntityImpl.invoke()` method (around line 370), not in `processInvokeRequest()` as originally planned. This ensures invocations are tracked at the right point in the entity lifecycle.

=== 1. MetricsRegistry (Central Registry)

**Location**: `com.tc.stats.logged.metric.MetricsRegistry.java`

**Responsibilities**:

* Hold separate maps for gauge and meter metrics
* Provide thread-safe access to metrics by name
* Simple registry pattern - no business logic

NOTE: Metric name constants (V, P, C, F, S, EIC, CIC, SIC, QIC) should be defined in `StatisticsService` or a separate `MetricNames` constants class, not in the registry.

[source,java]
----
public class MetricsRegistry {
  // Separate maps for different metric types (using concrete types)
  private final Map<String, Gauge> gauges;
  private final Map<String, Counter> counters;
  private final Map<String, MeteredCounter> meteredCounters;

  public MetricsRegistry() {
    this.gauges = new ConcurrentHashMap<>();
    this.counters = new ConcurrentHashMap<>();
    this.meteredCounters = new ConcurrentHashMap<>();
  }

  /**
   * Get or create and register a gauge.
   * @param name the metric name
   * @param valueSupplier supplier that provides the current value
   * @return the Gauge instance (newly created or existing)
   */
  public Gauge getOrCreateGauge(String name, LongSupplier valueSupplier) {
    return gauges.computeIfAbsent(name, k -> new Gauge(valueSupplier));
  }

  /**
   * Get or create and register a counter.
   * @param name the metric name
   * @return the Counter instance (newly created or existing)
   */
  public Counter getOrCreateCounter(String name) {
    return counters.computeIfAbsent(name, k -> new Counter());
  }

  /**
   * Get or create and register a metered counter.
   * @param meteredCounterName the name for the metered counter
   * @param parentCounterName the name of the parent counter to track
   * @return the MeteredCounter instance (newly created or existing)
   */
  public MeteredCounter getOrCreateMeteredCounter(String meteredCounterName, String parentCounterName) {
    return meteredCounters.computeIfAbsent(meteredCounterName, k -> {
      Counter parentCounter = getOrCreateCounter(parentCounterName);
      return new MeteredCounter(parentCounter);
    });
  }

  /**
   * Get a gauge by name.
   * @return Optional containing the gauge, or empty if not found
   */
  public Optional<Gauge> getGauge(String name) {
    return Optional.ofNullable(gauges.get(name));
  }

  /**
   * Get a counter by name.
   * @return Optional containing the counter, or empty if not found
   */
  public Optional<Counter> getCounter(String name) {
    return Optional.ofNullable(counters.get(name));
  }

  /**
   * Get a metered counter by name.
   * @return Optional containing the metered counter, or empty if not found
   */
  public Optional<MeteredCounter> getMeteredCounter(String name) {
    return Optional.ofNullable(meteredCounters.get(name));
  }

  /**
   * Get all gauges.
   */
  public Map<String, Gauge> getAllGauges() {
    return Collections.unmodifiableMap(gauges);
  }

  /**
   * Get all counters.
   */
  public Map<String, Counter> getAllCounters() {
    return Collections.unmodifiableMap(counters);
  }

  /**
   * Get all metered counters.
   */
  public Map<String, MeteredCounter> getAllMeteredCounters() {
    return Collections.unmodifiableMap(meteredCounters);
  }

  /**
   * Create a snapshot of all metrics.
   * Reads current values from gauges, counters, and resets metered counters.
   * @return Map of metric names to their current values
   */
  public Map<String, Long> snapshot() {
    Map<String, Long> snapshot = new HashMap<>();

    // Snapshot gauges (current values)
    gauges.forEach((name, gauge) -> snapshot.put(name, gauge.get()));

    // Snapshot counters (current values)
    counters.forEach((name, counter) -> snapshot.put(name, counter.get()));

    // Snapshot and reset metered counters
    meteredCounters.forEach((name, counter) -> snapshot.put(name, counter.getAndReset()));

    return snapshot;
  }
}

==== Counter

Monotonically increasing counter with overflow handling:

[source,java]
----
public class Counter implements Metric {
  private final AtomicLong value;

  public Counter() {
    this.value = new AtomicLong(0);
  }

  /**
   * Increment the counter by 1.
   * Handles Long.MAX_VALUE wrap to 0.
   */
  public void increment() {
    increment(1);
  }

  /**
   * Increment the counter by n.
   * Handles Long.MAX_VALUE wrap to 0.
   * @param n positive value to add (must be > 0)
   */
  public void increment(long n) {
  if (n == 0) {
      return;
    }
    if (n < 0) {
      throw new IllegalArgumentException("Increment value must be positive: " + n);
    }
    long current;
    long next;
    do {
      current = value.get();
      // Check if adding n would overflow
      if (current > Long.MAX_VALUE - n) {
        // Overflow: wrap around
        next = n - (Long.MAX_VALUE - current) - 1;
      } else {
        next = current + n;
      }
    } while (!value.compareAndSet(current, next));
  }

  @Override
  public long get() {
    return value.get();
  }

  @Override
  public String toString() {
    return getClass().getSimpleName() + ":" + get();
  }
}

==== MeteredCounter

Tracks delta since last reset, handling counter overflow:

[source,java]
----
public class MeteredCounter implements Metric {
  private final Counter counter;
  private final AtomicLong lastSnapshot;

  /**
   * Create a new metered counter that wraps an existing counter.
   * @param parent the parent counter to track deltas for
   */
  public MeteredCounter(Counter parent) {
    this.counter = parent;
    this.lastSnapshot = new AtomicLong(0);
  }

  /**
   * Increment the parent counter by 1.
   * Convenience method that delegates to the parent counter.
   */
  public void increment() {
    counter.increment();
  }

  /**
   * Increment the parent counter by n.
   * Convenience method that delegates to the parent counter.
   * @param n positive value to add (must be > 0)
   */
  public void increment(long n) {
    counter.increment(n);
  }

  /**
   * Get current delta since last snapshot.
   * Handles counter overflow.
   */
  @Override
  public long get() {
    long current = counter.get();
    long last = lastSnapshot.get();

    if (current >= last) {
      // No overflow
      return current - last;
    } else {
      // Overflow occurred: counter wrapped from MAX_VALUE to 0
      return (Long.MAX_VALUE - last) + current + 1;
    }
  }

  /**
   * Get current delta and reset.
   * Returns delta since last snapshot.
   */
  public long getAndReset() {
    long current = counter.get();
    long last = lastSnapshot.getAndSet(current);

    if (current >= last) {
      // No overflow
      return current - last;
    } else {
      // Overflow occurred
      return (Long.MAX_VALUE - last) + current + 1;
    }
  }

  @Override
  public String toString() {
    return getClass().getSimpleName() + ":" + get();
  }
}

        }
      }
    }
  }

**Key Differences:**

* **ClientMetricProvider**: Tracks ClientID lifecycle (logical clients)
- Called from `ClientChannelLifeCycleHandler.notifyClientAdded/Removed()`
- Tracks when a ClientID first appears and finally disappears

* **ConnectionMetricProvider**: Tracks physical connections (all channels)

- Tracks every TCP/IP connection creation/removal
- Same ClientID can have multiple connections over time

      } else {
        votes.remove(key);
        voters.remove(key);

        // Track metric on timeout
        if (voterMetricProvider != null) {
          voterMetricProvider.onVoterLeave(key);
        }

        return null;
      }
    });

    // ... rest of method ...
  }

  @Override
  public int getRegisteredVoters() {
    return (int)voters.entrySet().stream()
        .filter((entry) -> {
          if (timeSource.currentTimeMillis() - entry.getValue() < VOTEBEAT_TIMEOUT) {
            return true;
          } else {
            String id = entry.getKey();
            votes.remove(id);
            voters.remove(id);

            // Track metric on timeout
            if (voterMetricProvider != null) {
              voterMetricProvider.onVoterLeave(id);
            }

            return false;
          }
        })
        .count();
  }

  // NOTE: These static entity type constants need to be refactored to come from

    } else if (STORE_ENTITIES.contains(entityClassName)) {
      storeInvocations.increment();
    } else if (SEQUENCE_ENTITIES.contains(entityClassName)) {
      sequenceInvocations.increment();
    }
  }
}

public class StatisticsLogger implements StateChangeListener {
  private static final Logger LOGGER = LoggerFactory.getLogger("com.tc.stats.logged");
  private static final String PERIOD_PROPERTY = "org.terracotta.statistics.logging.period";
  private static final int DEFAULT_PERIOD_SECONDS = 300;

  private final ScheduledExecutorService scheduler;
  private final MetricsRegistry registry;
  private final StatisticsFormatter formatter;
  private final TopologyCollector topologyCollector;
  private final int periodSeconds;

  private volatile long lastLogTime;
  private volatile ScheduledFuture<?> nextExecution;
  private volatile boolean running;

  public StatisticsLogger(MetricsRegistry registry, TopologyCollector topologyCollector) {
    this.registry = registry;
    this.topologyCollector = topologyCollector;
    this.formatter = new StatisticsFormatter();
    this.periodSeconds = getPeriodFromProperty();
    this.scheduler = Executors.newSingleThreadScheduledExecutor(
      new DaemonThreadFactory("statistics-logger"));
    this.running = false;
  }

  public synchronized void start() {
    if (running) {
      return;
    }
    running = true;
    lastLogTime = System.currentTimeMillis() / 1000;
    scheduleNext();
    LOGGER.info("Statistics logging started with period: {} seconds", periodSeconds);
  }

  public synchronized void stop() {
    running = false;
    if (nextExecution != null) {
      nextExecution.cancel(false);
    }
    scheduler.shutdown();
    LOGGER.info("Statistics logging stopped");
  }

  /**
   * Schedule the next execution (not fixed rate).
   */
  private void scheduleNext() {
    if (!running) {
      return;
    }
    nextExecution = scheduler.schedule(
      () -> {
        try {
          logStatistics(LoggingTrigger.PERIODIC);
        } finally {
          scheduleNext();
        }
      },
      periodSeconds,
      TimeUnit.SECONDS
    );
  }

  /**
   * Log statistics immediately (for events).
   */
  public synchronized void logNow(LoggingTrigger trigger) {
    if (!running) {
      return;
    }
    logStatistics(trigger);
  }

  /**
   * Atomically collect metrics, reset deltas, and log.
   */
  private synchronized void logStatistics(LoggingTrigger trigger) {
    try {
      long currentTime = System.currentTimeMillis() / 1000;
      long secondsSinceLast = currentTime - lastLogTime;

      // Snapshot all metrics (reads gauges, resets metered counters)
      Map<String, Long> metrics = registry.snapshot();

      // Collect topology
      String topology = topologyCollector.collectTopology();

      // Format and log
      String logLine = formatter.format(currentTime, metrics, topology, secondsSinceLast);
      LOGGER.info(logLine);

      lastLogTime = currentTime;

      if (trigger != LoggingTrigger.PERIODIC) {
        LOGGER.debug("Statistics logged due to: {}", trigger);
      }
    } catch (Exception e) {
      LOGGER.error("Error logging statistics", e);
    }
  }

  /**
   * StateChangeListener implementation - log on topology changes.
   */
  @Override
  public void l2StateChanged(StateChangedEvent sce) {
    // Log on state changes (active/passive transitions, failover, etc.)
    logNow(LoggingTrigger.TOPOLOGY_CHANGE);
  }

  private int getPeriodFromProperty() {
    String value = TCPropertiesImpl.getProperties()
      .getProperty(PERIOD_PROPERTY, String.valueOf(DEFAULT_PERIOD_SECONDS));
    try {
      int period = Integer.parseInt(value);
      if (period <= 0) {
        LOGGER.warn("Invalid period value: {}, using default: {}",
          value, DEFAULT_PERIOD_SECONDS);
        return DEFAULT_PERIOD_SECONDS;
      }
      return period;
    } catch (NumberFormatException e) {
      LOGGER.warn("Invalid period value: {}, using default: {}",
        value, DEFAULT_PERIOD_SECONDS);
      return DEFAULT_PERIOD_SECONDS;
    }
  }
}

enum LoggingTrigger {
  PERIODIC,
  TOPOLOGY_CHANGE,
  FAILOVER,
  // ...
}

public class StatisticsFormatter {
  private static final int MIN_GAUGE_WIDTH = 4;
  private static final int MIN_DELTA_WIDTH = 3;

  public String format(long timestamp, Map<String, Long> metrics, String topology, long secondsSinceLast) {
    StringBuilder sb = new StringBuilder();

    // Header: STATS:<unix>:<seconds>
    sb.append("STATS:").append(timestamp)
      .append(":").append(secondsSinceLast);

    // Topology
    sb.append("|").append(topology);

    // Metrics with dynamic width
    appendMetric(sb, "V",
      metrics.get(MetricNames.VOTERS),
      metrics.get(MetricNames.VOTERS_PLUS),
      metrics.get(MetricNames.VOTERS_MINUS));
    appendMetric(sb, "P",
      metrics.get(MetricNames.PHYSICAL_CONNECTIONS),
      metrics.get(MetricNames.PHYSICAL_CONNECTIONS_PLUS),
      metrics.get(MetricNames.PHYSICAL_CONNECTIONS_MINUS));
    appendMetric(sb, "C",
      metrics.get(MetricNames.CLIENTS),
      metrics.get(MetricNames.CLIENTS_PLUS),
      metrics.get(MetricNames.CLIENTS_MINUS));
    appendMetric(sb, "F",
      metrics.get(MetricNames.ENTITY_FETCHES),
      metrics.get(MetricNames.ENTITY_FETCHES_PLUS),
      metrics.get(MetricNames.ENTITY_FETCHES_MINUS));
    appendMetric(sb, "S",
      metrics.get(MetricNames.SERVERS),
      metrics.get(MetricNames.SERVERS_PLUS),
      metrics.get(MetricNames.SERVERS_MINUS));

    // Meter-only metrics
    appendMeter(sb, "EIC", metrics.get(MetricNames.TOTAL_ENTITY_INVOCATIONS));
    appendMeter(sb, "CIC", metrics.get(MetricNames.CACHE_ENTITY_INVOCATIONS));
    appendMeter(sb, "SIC", metrics.get(MetricNames.STORE_ENTITY_INVOCATIONS));
    appendMeter(sb, "QIC", metrics.get(MetricNames.SEQUENCE_ENTITY_INVOCATIONS));

    return sb.toString();
  }

  private void appendMetric(StringBuilder sb, String label, long current, long plus, long minus) {
    sb.append("|").append(label).append(":");

    // Determine width based on largest value
    int width = Math.max(MIN_GAUGE_WIDTH, String.valueOf(current).length());
    int deltaWidth = Math.max(MIN_DELTA_WIDTH,
      Math.max(String.valueOf(plus).length() + 1, String.valueOf(minus).length() + 1));

    sb.append(formatNumber(current, width, false))
      .append(",")
      .append(formatNumber(plus, deltaWidth, true))
      .append(",")
      .append(formatNumber(minus, deltaWidth, true, true));
  }

  private void appendMeter(StringBuilder sb, String label, long value) {
    sb.append("|").append(label).append(":");
    int width = Math.max(MIN_DELTA_WIDTH, String.valueOf(value).length() + 1);
    sb.append(formatNumber(value, width, true));
  }

  private String formatNumber(long value, int width, boolean withSign) {
    return formatNumber(value, width, withSign, false);
  }

  private String formatNumber(long value, int width, boolean withSign, boolean negative) {
    String sign = "";
    if (withSign) {
      sign = negative ? "-" : "+";
    }
    String numStr = String.valueOf(value);
    int padding = width - sign.length() - numStr.length();
    return sign + "0".repeat(Math.max(0, padding)) + numStr;
  }
}
